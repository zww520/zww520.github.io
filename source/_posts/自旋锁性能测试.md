### 自旋锁原理

当一个线程尝试获取已被其他线程持有的锁时，它不会立即让出CPU（如进入睡眠），而是会在一个循环中反复检查锁的状态，直到锁被释放

### 自旋锁实现

#### 普通自旋锁

通过CPU指令实现线程 `yield` ，比直接调用 `std::this_thread::yield`更快，开销更低

由于频繁等待，触发大量CPU的RFO操作，导致性能极差

```cpp
class SpinLock {
public:
    void lock() {
        // 循环尝试：test_and_set 会原子地将 flag 设为 true 并返回旧值
        // 如果旧值是 false（未锁定），则成功获取锁，退出循环
        // 如果旧值是 true（已锁定），则继续忙等待
        while (flag.test_and_set(std::memory_order_acquire)) {
            // 可选的 CPU 暂停指令，减少功耗和竞争
            #ifdef __x86_64__
            __asm__ volatile("pause" ::: "memory");
            #elif defined(__aarch64__)
            __asm__ volatile("yield" ::: "memory");
            #elif defined(__arm__)
            __asm__ volatile("yield" ::: "memory");
            #else
            std::this_thread::yield();
            #endif

        }
    }

    void unlock() {
        // 原子地将 flag 清除为 false（解锁）
        flag.clear(std::memory_order_release);
    }

    // 尝试加锁，非阻塞
    bool try_lock() {
        // 如果旧值是 false，则成功获取锁
        return !flag.test_and_set(std::memory_order_acquire);
    }
private:
    std::atomic_flag flag = ATOMIC_FLAG_INIT;  // 初始化为 false（未锁定）    
};
```

#### 带Backoff机制的自旋锁

通过Backoff机制，逐步提高等待时间，避免频繁访问变量导致大量RFO，性能大幅度提高

```cpp
class AdaptiveSpinLock {
public:
    void lock() {
        int backoff = 1;
        while (true) {
            // 快速路径：尝试直接获取
            if (!_lock.exchange(true, std::memory_order_acquire)) {
                return;
            }

            // 退避等待：先自旋几次，再让出 CPU
            for (int i = 0; i < backoff; ++i) {
                // 可选的 CPU 暂停指令，减少功耗和竞争
                #ifdef __x86_64__
                __asm__ volatile("pause" ::: "memory");
                #elif defined(__aarch64__)
                __asm__ volatile("yield" ::: "memory");
                #elif defined(__arm__)
                __asm__ volatile("yield" ::: "memory");
                #else
                std::this_thread::yield();
                #endif
            }

            // 指数退避，限制上限
            backoff = std::min(backoff << 1, 64);
        }
    }

    void unlock() {
        _lock.store(false, std::memory_order_release);
    }

    bool try_lock() {
        return !_lock.exchange(true, std::memory_order_acquire);
    }
private:
    std::atomic<bool> _lock{false};
};
```

### 性能测试

#### 测试结果

|       锁类型        |  耗时  |        参数         |
| :-----------------: | :----: | :-----------------: |
|        mutex        | 2256ms | worker=8，count=1e9 |
|      spinlock       | 4670ms | worker=8，count=1e9 |
| spinlock（backoff） | 3688ms | worker=8，count=1e9 |

#### 测试结论

如果没有必要，由于`mutex`内部自带优化，如无必要直接使用`mutex`进行临界区加锁是最好的，

#include <iostream>
#include <chrono>
#include <vector>
#include <thread>
#include <mutex>
#include "spinlock.h"

using namespace std;
using namespace chrono;

const int NUM_THREADS = 1;
const int MAX_COUNT = 100000000;

static int count = 0;

void addCountSpinLock(SpinLock &lock) {
    bool flag = false;
    while(1) {
        lock.lock();

        if(count >= MAX_COUNT) {
            flag = true;
        } else {
            count++;
        }

        lock.unlock();
        if(flag) {
            break;
        }
    }
}

void addCountAdaptiveSpinLock(AdaptiveSpinLock &lock) {
    bool flag = false;
    while(1) {
        lock.lock();

        if(count >= MAX_COUNT) {
            flag = true;
        } else {
            count++;
        }

        lock.unlock();
        if(flag) {
            break;
        }
    }
}

void addCountMutex(std::mutex &lock) {
    bool flag = false;
    while(1) {
        lock.lock();

        if(count >= MAX_COUNT) {
            flag = true;
        } else {
            count++;
        }

        lock.unlock();
        if(flag) {
            break;
        }
    }
}

void mutex_test() { 
    std::cout << "mutex_test" << std::endl;

    auto start = high_resolution_clock::now();

    std::mutex lock;
    count = 0;
    std::vector<std::thread> workers;
    for(int i = 0; i < NUM_THREADS; i++) {
        workers.emplace_back(addCountMutex, std::ref(lock));
    }
    for(auto &worker : workers) {
        worker.join();
    }

    auto end = high_resolution_clock::now();

    std::cout << "mutex_test count=" << count << " time=" << duration_cast<milliseconds>(end - start).count() << " ms" << std::endl;

}
