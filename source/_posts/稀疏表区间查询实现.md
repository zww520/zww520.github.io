## 稀疏表区间查询实现

### 稀疏表介绍

稀疏表（Sparse Table）是一种用于解决可重复贡献问题的数据结构，最经典的应用是RMQ（区间最值查询）。

| 维度       | 复杂度          | 备注                                     |
| ---------- | --------------- | ---------------------------------------- |
| 预处理时间 | \(O(n \log n)\) | 双层循环，外层 \(\log n\) 层，内层 \(n\) |
| 空间占用   | \(O(n \log n)\) | `st[n][log n]` 二维数组                  |
| 单次查询   | \(O(1)\)        | 只需两次数组访问 + 一次操作              |
| 适用范围   | 静态数据        | 不支持修改操作                           |

### 稀疏表原理

预处理所有长度为\(2^k\) 的区间的最值，查询时将任意区间\([l, r]\)拆分成两个可重叠的、长度为 \(2^k\) 的区间进行合并。

**关键性质**：对于满足结合律且 **重复计算不影响结果** 的操作（如 min、max、gcd、按位与），区间可以重叠覆盖。

**核心思想**：\(st[i][k]\)表示从位置 i 开始、长度为 \(2^k\)  的区间的最值

```text
st[i][0] = arr[i]
st[i][k] = op(st[i][k-1], st[i + 2^(k-1)][k-1])
```

**查询原理**：对于查询 \([l, r]\)，区间长度\( len = r - l + 1\)，找到最大的 k 使得\(2^k≤len\)

```text
ans = op( st[l][k], st[r - 2^k + 1][k] )
```

### 稀疏表实现

sparse_table.h

```cpp
#ifndef SPARSE_TABLE_H
#define SPARSE_TABLE_H

#include <cstdint>
#include <cmath>
#include <vector>

using std::vector;
template<typename T>
class SparseTable {
public:
    SparseTable() = default;
    ~SparseTable() = default;
public:
    void build(const vector<T>& arr) {
        int n = arr.size();
        int K = log2(n) + 1;
        stData = arr;
        stMinIndex.resize(n);
        stMaxIndex.resize(n);
        logTable.resize(n + 1);
        logTable[1] = 0;
        for (int i = 2; i <= n; i++) {
            logTable[i] = logTable[i >> 1] + 1;
        }
        for (int i = 0; i < n; i++) {
            stMinIndex[i].resize(K);
            stMaxIndex[i].resize(K);
            stMinIndex[i][0] = i;
            stMaxIndex[i][0] = i;
        }
        
        for (int j = 1; j < K; j++) {
            for (int i = 0; i + (1 << j) <= n; i++) {
                auto lindex = stMinIndex[i][j-1];
                auto rindex = stMinIndex[i + (1 << (j-1))][j-1];
                if(stData[lindex] < stData[rindex]) {
                    stMinIndex[i][j] = lindex;
                } else {
                    stMinIndex[i][j] = rindex;
                }
                lindex = stMaxIndex[i][j-1];
                rindex = stMaxIndex[i + (1 << (j-1))][j-1];
                if(stData[lindex] > stData[rindex]) {
                    stMaxIndex[i][j] = lindex;
                } else {
                    stMaxIndex[i][j] = rindex;
                }   
            }
        }
    }
    T rangeMin(int l, int r) {
        int k = logTable[r - l + 1];
        auto lindex = stMinIndex[l][k];
        auto rindex = stMinIndex[r - (1 << k) + 1][k];
        return std::min(stData[lindex], stData[rindex]);
    }
    T rangeMax(int l, int r) {
        int k = logTable[r - l + 1];
        auto lindex = stMaxIndex[l][k];
        auto rindex = stMaxIndex[r - (1 << k) + 1][k];
        return std::max(stData[lindex], stData[rindex]);
    }
    int32_t rangeMinIndex(int l, int r) {
        if(l > r) return -1;
        if(l == r) return l;
        if(l < 0 || r >= stData.size()) return -1;
        
        int k = logTable[r - l + 1];
        auto lindex = stMinIndex[l][k];
        auto rindex = stMinIndex[r - (1 << k) + 1][k];
        if(stData[lindex] < stData[rindex]) {
            return lindex;
        } else {
            return rindex;
        }
        return lindex;
    }
    int32_t rangeMaxIndex(int l, int r) {
        if(l > r) return -1;
        if(l == r) return l;
        if(l < 0 || r >= stData.size()) return -1;

        int k = logTable[r - l + 1];
        auto lindex = stMaxIndex[l][k];
        auto rindex = stMaxIndex[r - (1 << k) + 1][k];
        if(stData[lindex] >= stData[rindex]) {
            return lindex;
        } else {
            return rindex;
        }
        return lindex;
    }
private:
    std::vector<T> stData;
    std::vector<int32_t> logTable;
    std::vector<std::vector<int32_t>> stMinIndex;
    std::vector<std::vector<int32_t>> stMaxIndex;
};

#endif // SPARSE_TABLE_H


```
