### 梅尔频谱介绍

梅尔频谱（Mel Spectrogram）是一种模仿人耳听觉特性的音频信号时频表示方法。简单来说，它是对普通频谱图进行了一次“心理声学”改造，让频率刻度和能量感知都更接近我们人类实际的听觉感受

### 语谱图使用梅尔频谱的优点

#### 1. 模拟人耳的非线性频率感知（更符合听觉生理）

人耳对频率的分辨率不是线性的，而是类似一个对数滤波器组——**低频分辨率高，高频分辨率低**。

- **普通语谱图**：使用线性频率刻度（Hz）。在频谱上，低频区域（如0-1kHz）和高频区域（如4-5kHz）占用同样的宽度。这导致机器会“过度关注”人类耳朵实际上很难区分的高频细微差异，而忽略了低频中对人类语音理解至关重要的细微变化（如元音区分）
- **梅尔语谱图**：使用梅尔刻度，它将低频区域拉伸变宽（更精细），将高频区域压缩变窄（更粗糙）。这使得语谱图的频域分辨率分布与人类耳蜗基底膜的振动模式完全一致。因此，机器看到的特征和我们听到的“语音敏感度”是同步的

#### 2.压缩响度动态范围（更符合听觉响度）

人耳对声音强度的感知也不是线性的，而是近似对数的（即韦伯-费希纳定律）

- **普通语谱图**：通常显示线性能量或幅度，能量大的频率成分（如基频）会掩盖能量小但对识别重要的共振峰信息
- **梅尔语谱图**：在应用梅尔滤波器后，会强制进行对数运算（log）。这能将信号幅度的宽动态范围压缩到较小的范围内，使得微弱的高次共振峰和噪声音量被“拉高”，从而在语谱图上显示得更清楚，便于机器提取这些隐藏的细节特征

#### 3.降维与去冗余（更适合深度学习模型）

这对于现代基于神经网络的语音识别（ASR）和语音合成（TTS）尤其重要。

- **普通语谱图**：在短时傅里叶变换（STFT）后，通常会保留 257 或 513 个频点（FFT 长度 的一半）。这些频点之间高度相关（相邻频点的能量往往相近），存在大量的信息冗余，直接输入会浪费算力
- **梅尔语谱图**：通常只取 **64 到 128 个滤波器通道（Mel bands）**。这相当于对原始的 513 维频谱进行了智能降维，提取出平滑的谱包络（忽略细微的谐波梳齿）。数据量大幅减少，但同时保留了最关键的共振峰结构，成为如今深度学习声学模型最主流、最高效的输入特征

### 梅尔谱计算流程

#### 1. 音频数据读取分帧

每帧长度，建议取25ms，帧移（当前帧与上一帧重叠大小）可以选10ms

```cpp
int32_t readNextAudioFrame(int16_t *input, int32_t inputSize, int32_t curPos, int32_t frameLen, int32_t overlay, int16_t *output)
{
    if(curPos+frameLen>inputSize) {
        return 0;
    }
    int32_t index = curPos;
    for(int i=0;i<frameLen;i++) {
        output[i] = input[index];
        index += 1;
    }
    return curPos+frameLen-overlay;
}
```

#### 2. 数据预加重

通过数据预加重补偿语音信号中高频部分的能量衰减，增强高频共振峰

公式如下表示，$α$一般取0.95
$$
y[n]=x[n]−α⋅x[n−1]
$$
代码实现：

```cpp
for(int k=1;k<frameLen;k++) {
    input[k] = input[k] - 0.95*input[k-1];
}
```

#### 3. 信号加窗

输入数据加窗，减少 FFT 产生的频谱泄漏，一般使用汉宁窗（Hanning）

汉宁窗公式：
$$
w[n] = \frac{1}{2}\left[1 - \cos\left(\frac{2\pi n}{N-1}\right)\right], \quad n = 0,1,\ldots,N-1
$$
加窗公式：
$$
x_w[n] = x[n] \cdot w[n]x_w[n] = x[n] \cdot w[n]
$$
代码实现

```cpp
double applyHanningWindow(double* buffer, int length)
{
    double sum = 0.0;
    for (int i = 0; i < length; i++) {
        double w = 0.5 * (1.0 - std::cos(2.0 * M_PI * i / (length - 1))); // 汉宁窗函数
        buffer[i] *= w;
        sum += w;
    }
    return length / sum; // 窗函数增益
}
```

#### 4. FFT计算幅度谱

使用PFFFT计算实信号幅度谱

```cpp
PFFFTD_Setup* setup = pffftd_new_setup(length, PFFFT_REAL); // 创建PFFFT设置
double* inputBuffer = (double*)pffftd_aligned_malloc(length * sizeof(double));
double* outputBuffer = (double*)pffftd_aligned_malloc(length * sizeof(double));
double* workBuffer = (double*)pffftd_aligned_malloc(length * sizeof(double));

double mean = 0.0;
for (int i = 0; i < length; i++) {
    mean += buffer[i]; // 计算平均值
}
mean /= length; // 平均值
for (int i = 0; i < length; i++) {
    inputBuffer[i] = buffer[i] - mean; // 去掉直流分量
}

// 应用汉宁窗，减少频谱泄漏，并获取窗函数的相干增益用于补偿
double windowGain = 1.0;
windowGain = applyHanningWindow(inputBuffer, length);

pffftd_transform_ordered(setup, inputBuffer, outputBuffer, workBuffer, PFFFT_FORWARD);

int half = length / 2;
for (int i = 0; i <= half; i++) {
    if (i == 0) {
        double real = outputBuffer[0];
        spectrum[i] = std::fabs(real) / length * windowGain; // DC 不乘2
    } else if (i == half) {
        double realNyq = outputBuffer[1];
        spectrum[i] = std::fabs(realNyq) / length * windowGain; // Nyquist 不乘2
    } else {
        double real = outputBuffer[2 * i];     // 实部
        double imag = outputBuffer[2 * i + 1]; // 虚部
        spectrum[i] = std::sqrt(real * real + imag * imag) * 2.0 / length * windowGain; // 单边幅度并补偿窗函数
    }
}
pffftd_aligned_free(inputBuffer); // 释放内存
pffftd_aligned_free(outputBuffer);
pffftd_aligned_free(workBuffer);
pffftd_destroy_setup(setup); // 销毁PFFFT设置
```

#### 5.幅度谱转功率谱

将幅度谱转为功率谱，$A(k)$为幅度值
$$
P(k) = 10 \log_{10}\left( A(k)^2 \right)
$$

#### 6.应用梅尔滤波器组

目的：将线性频率映射到梅尔尺度，模拟人耳听觉特性，滤波器组个数可选128

物理刻度转梅尔频率：
$$
mel(f) = 2595 \times \log_{10}\left(1 + \frac{f}{700}\right)
$$
梅尔刻度转物理频率：
$$
mel^{-1}(m) = 700 \times \left(10^{m/2595} - 1\right)
$$
梅尔滤波器定义：梅尔滤波器组是一组三角形滤波器，相邻两个滤波器间重叠50%，如第一个滤波器区间为$[ml1, mm1, mr1]$，第二个滤波器区间则为$[mm1, mr1, mr2]$

![mel-bands](img\resources\mel-bands.png)

梅尔滤波器代码实现

```cpp
class MelFilterBank {
private:
    int num_filters;          // 滤波器数量
    int fft_size;            // FFT点数
    int sample_rate;         // 采样率（Hz）
    double min_freq;         // 最低频率（Hz）
    double max_freq;         // 最高频率（Hz）
    std::vector<std::vector<double>> filter_bank;  // 滤波器组 [num_filters][fft_size/2+1]

    /**
     * 将频率转换为Mel刻度
     */
    double hzToMel(double hz) {
        return 2595.0 * log10(1.0 + hz / 700.0);
    }

    /**
     * 将Mel刻度转换为频率
     */
    double melToHz(double mel) {
        return 700.0 * (pow(10.0, mel / 2595.0) - 1.0);
    }

    /**
     * 计算三角滤波器的响应
     */
    double triangularFilter(double freq, double left, double center, double right) {
        if (freq < left || freq > right) {
            return 0.0;
        }
        if (freq <= center) {
            return (freq - left) / (center - left);
        } else {
            return (right - freq) / (right - center);
        }
    }

public:
    /**
     * 构造函数
     * @param num_filters_ 滤波器数量
     * @param fft_size_ FFT大小
     * @param sample_rate_ 采样率
     * @param min_freq_ 最低频率（默认0）
     * @param max_freq_ 最高频率（默认采样率/2）
     */
    MelFilterBank(int num_filters_, int fft_size_, int sample_rate_,
                  double min_freq_ = 0.0, double max_freq_ = -1.0)
        : num_filters(num_filters_),
          fft_size(fft_size_),
          sample_rate(sample_rate_),
          min_freq(min_freq_) {

        // 如果未指定最大频率，使用奈奎斯特频率
        if (max_freq_ < 0) {
            max_freq = sample_rate_ / 2.0;
        } else {
            max_freq = max_freq_;
        }

        // 确保频率范围有效
        assert(min_freq < max_freq);
        assert(num_filters > 0);
        assert(fft_size > 0);

        buildFilterBank();
    }

    /**
     * 构建Mel滤波器组
     */
    void buildFilterBank() {
        int num_bins = fft_size / 2 + 1;  // 频率点数
        filter_bank.resize(num_filters, std::vector<double>(num_bins, 0.0));

        // 1. 在Mel刻度上均匀分布滤波器中心点
        double mel_min = hzToMel(min_freq);
        double mel_max = hzToMel(max_freq);
        double mel_step = (mel_max - mel_min) / (num_filters + 1);

        // 存储所有中心点（Mel刻度）
        std::vector<double> mel_centers(num_filters + 2);
        for (int i = 0; i < num_filters + 2; ++i) {
            mel_centers[i] = mel_min + i * mel_step;
        }

        // 转换为频率（Hz）
        std::vector<double> hz_centers(num_filters + 2);
        for (int i = 0; i < num_filters + 2; ++i) {
            hz_centers[i] = melToHz(mel_centers[i]);
        }

        // 2. 计算每个频率点的FFT bin索引
        std::vector<double> freq_bins(num_bins);
        for (int i = 0; i < num_bins; ++i) {
            freq_bins[i] = (double)i * sample_rate / fft_size;
        }

        // 3. 构建每个三角滤波器
        for (int i = 0; i < num_filters; ++i) {
            double left = hz_centers[i];
            double center = hz_centers[i + 1];
            double right = hz_centers[i + 2];

            // 如果中心点超出范围，跳过
            if (center <= min_freq || center >= max_freq) {
                continue;
            }

            // 计算该滤波器的响应
            for (int j = 0; j < num_bins; ++j) {
                double freq = freq_bins[j];
                if (freq >= left && freq <= right) {
                    filter_bank[i][j] = triangularFilter(freq, left, center, right);
                }
            }

            // 可选：归一化滤波器（使每个滤波器的面积相等）
            // double sum = std::accumulate(filter_bank[i].begin(), filter_bank[i].end(), 0.0);
            // if (sum > 0) {
            //     for (auto& val : filter_bank[i]) {
            //         val /= sum;
            //     }
            // }
        }
    }

    /**
     * 应用Mel滤波器组到功率谱
     * @param power_spectrum 功率谱（长度必须为fft_size/2+1）
     * @return Mel能量向量（长度为num_filters）
     */
    std::vector<double> apply(const std::vector<double>& power_spectrum) const {
        assert(power_spectrum.size() == filter_bank[0].size());

        std::vector<double> mel_energy(num_filters, 0.0);

        for (int i = 0; i < num_filters; ++i) {
            double energy = 0.0;
            for (size_t j = 0; j < power_spectrum.size(); ++j) {
                energy += filter_bank[i][j] * power_spectrum[j];
            }
            // 避免log(0)
            if (energy < 1e-10) {
                energy = 1e-10;
            }
            mel_energy[i] = energy;
        }

        return mel_energy;
    }

    /**
     * 获取滤波器组（用于可视化或调试）
     */
    const std::vector<std::vector<double>>& getFilterBank() const {
        return filter_bank;
    }
};
```



#### 7.最终结果

**梅尔频谱（Mel Spectrogram）** 是一个二维矩阵：

- **行（M）**：梅尔滤波器个数（如 128 个频率通道）
- **列（T）**：时间帧数
